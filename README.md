# CodSoft

Machine Learning projects completed during the CodSoft internship.

## Overview

This repository contains machine learning projects developed as part of the CodSoft internship program. Each project applies ML techniques to solve real-world classification and prediction problems.

## Tech Stack

- Python
- Jupyter Notebook
- scikit-learn
- Pandas, NumPy
- Matplotlib / Seaborn

## Projects

| Notebook | Description |
|----------|-------------|
| `CODSOFT_CREDIT_CARD.ipynb` | Credit card fraud detection |
| `CODSOFT_IRIS.ipynb` | Iris flower classification |
| `CODSOFT_MOVIE_RATING.ipynb` | Movie rating prediction |
| `CODSOFT_SALES_PREDICTION.ipynb` | Sales prediction model |
| `CODSOFT_TITANIC.ipynb` | Titanic survival prediction |

## Getting Started

```bash
pip install jupyter scikit-learn pandas numpy matplotlib seaborn
jupyter notebook
```
