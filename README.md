## Overview

CodSoft is a collection of machine learning projects built during the CodSoft program. Each notebook tackles a distinct real-world classification or prediction problem using structured datasets and scikit-learn pipelines.

### Why CodSoft?

This project demonstrates practical ML skills across diverse domains. The core projects include:

- 💳🔍 **Credit Card Fraud Detection**: Binary classification to identify fraudulent transactions.
- 🌸🤖 **Iris Flower Classification**: Multi-class classification of flower species from measurements.
- 🎬⭐ **Movie Rating Prediction**: Regression model to predict IMDb movie ratings.
- 📈🛋️ **Sales Prediction**: Forecasting product sales using regression techniques.
- 🚢📊 **Titanic Survival Prediction**: Classic binary classification on the Titanic dataset.

## Getting Started

### Prerequisites

This project requires the following dependencies:

- **Programming Language**: Python 3.8+
- **Packages**: `scikit-learn`, `pandas`, `numpy`, `matplotlib`, `seaborn`

### Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/soumya0424/CodSoft
   cd CodSoft
   ```

2. **Install dependencies:**

   ```bash
   pip install scikit-learn pandas numpy matplotlib seaborn jupyter
   ```

### Usage

```bash
jupyter notebook
```

Open any notebook from the list below:

| Notebook | Problem Type |
|----------|--------------|
| `CODSOFT_CREDIT_CARD.ipynb` | Fraud Detection |
| `CODSOFT_IRIS.ipynb` | Flower Classification |
| `CODSOFT_MOVIE_RATING.ipynb` | Rating Prediction |
| `CODSOFT_SALES_PREDICTION.ipynb` | Sales Forecasting |
| `CODSOFT_TITANIC.ipynb` | Survival Prediction |
